# Design and investigation records

[Documentation](../README.md) / Design records

Plans preserve the reasoning and observations from a particular stage of
development. A plan's original proposal, later implementation and validation
updates are distinct; read its source and scope qualifications.

- [Exit-time history synchronization timeout](exit-sync-activity-timeout.md):
  investigation, recovery design and follow-up observations.
- [Native 2.3 recovery preparation for stable 1.6](native-2.3-recovery.md):
  historical scope and original validation requirements, not a new host pass.
- [Host-owned terminal input](trusted-terminal-input.md): possible clipboard
  and click authorization outside a raw PTY input stream.
- [Browser workspace runtime](web-runtime.md): opt-in workspace layouts,
  deferred TLS preparation and remaining named sign-in gates.
- [Stable 1.8 and development 1.9](stable-1.8-devel-1.9.md): initial feature
  parity, release gates, and the bug/security backport policy.
